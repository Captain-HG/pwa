# 个人记账 PWA —— 详细设计（v1.0）

> 依据：[需求分析与架构设计.md](需求分析与架构设计.md)。本文覆盖 v1.0（P0）范围的页面交互、组件、服务接口与关键算法。

---

## 1. 范围

v1.0 实现：

| 模块 | 内容 |
|---|---|
| 记账 | 新增 / 编辑 / 删除；支出、收入两种类型；金额键盘支持 `+ -` 算式 |
| 分类 | 预置分类；新增、改名、改图标、隐藏/显示、排序（上移/下移） |
| 流水 | 月份切换、月度汇总、按日分组、点击编辑、左滑删除 |
| 统计 | 支出/收入切换；分类环形图 + 排行；每日柱状图 |
| 备份 | JSON 导出 / 导入（覆盖、合并）；CSV 导出；超期备份提醒 |
| 设置 | 分类管理入口、备份入口、清空数据、版本信息 |

v1.0 **不含**：转账、多账户界面、预算、筛选搜索（数据模型已预留字段，后续版本开启）。
v1.0 后台自动创建一个「默认账户」，所有流水挂在该账户下。

## 2. 全局界面规范

| 项 | 规范 |
|---|---|
| 设计基准 | 375 × 812（iPhone X 及以上），宽度自适应 320–430 |

## 4. 页面设计

### 4.1 首页 / 明细（HomeView）

```
┌───────────────────────────────┐
│  ‹  2026年10月  ›               │  ← MonthSwitcher，点击中间弹出年月选择
├───────────────────────────────┤
│  本月支出                        │
│  3,256.80                       │  ← 大字
│  收入 8,000.00   结余 4,743.20    │
├───────────────────────────────┤
│  ⚠ 已 20 天未备份，去备份 ›        │  ← 条件显示（BackupReminder）
├───────────────────────────────┤
│  10月27日 周二      支出 58.00    │  ← 日分组头
│  🍜 餐饮  午饭          -28.00   │  ← 左滑出现「删除」
│  🚇 交通               -30.00   │
│  10月26日 周一 ...                │
├───────────────────────────────┤
│   明细     (＋)    统计    设置    │
└───────────────────────────────┘
```

交互：

- 进入时默认当前月；切换到未来月份不限制（可提前记账）。
- 点击流水 → `#/edit/:id`。
- 左滑 → 删除按钮 → 确认后软删除，Toast「已删除」。
- 空状态：`van-empty`，文案「本月还没有记账，点 ＋ 记一笔」。
- 数据通过 Dexie `liveQuery` 订阅，增删改后自动刷新。

### 4.2 记一笔（EditView）

```
┌───────────────────────────────┐
│ 取消        [支出|收入]     删除  │  ← 删除仅编辑时出现
├───────────────────────────────┤
│  🍜    🚇    🛍    🏠    🎮       │
│ 餐饮  交通  购物  居住  娱乐      │  ← CategoryGrid，选中高亮
│  💊    📚    🎁    📦    ⚙        │
│ 医疗  学习  人情  其他  管理       │  ← 「管理」进入分类管理
├───────────────────────────────┤
│ 备注：午饭____________   10月27日 │  ← 点击日期弹出日期时间选择
│                       ¥ 12.5+8  │  ← 表达式
│                          =20.50 │  ← 实时结果（有运算符时显示）
├───────────────────────────────┤
│  1   2   3   ⌫                  │
│  4   5   6   +                  │  ← AmountKeypad
│  7   8   9   -                  │
│  .   0   00  完成                │
└───────────────────────────────┘
```

交互规则：

1. 新增时默认类型「支出」，默认选中该类型下排序第一的分类，日期为当前时间。
2. 切换支出/收入时，分类宫格切换为对应类型，已选分类重置为该类型的第一个。
3. 键盘输入规则（见 §6.2）。
4. 「完成」：表达式求值 → 结果 ≤ 0 时 Toast「请输入金额」；否则保存并返回上一页，Toast「已保存」。
5. 若表达式含运算符，键盘「完成」键显示为「=」，点击先求值替换表达式，再次点击才保存。
6. 编辑时预填所有字段，金额显示为元（如 `20.5`）。

- 无数据时显示空状态，不渲染图表。
- 图表跟随深色模式切换文字颜色。

### 4.4 设置（SettingsView）

单元格列表：

- 分类管理 →
- 备份与恢复 →（右侧显示「上次备份：x 天前 / 从未备份」）
- 清空所有数据（红色，需输入「确认清空」才可执行，执行后重新写入预置数据）
- 关于：版本号、存储是否已持久化（`navigator.storage.persisted()`）

### 4.5 分类管理（CategoryView）

- 顶部 Tab：支出 / 收入。
- 列表项：图标、名称、右侧「↑ ↓」排序按钮、隐藏开关。
- 点击项 → 弹窗编辑名称与图标（图标从预置 emoji 面板中选）。
- 底部「新增分类」。
- 名称校验：1–8 个字符，同类型下不可重名。
- 不提供删除（避免孤儿流水），用隐藏代替；隐藏的分类不出现在记账宫格中，但历史流水仍正常显示。

### 4.6 备份与恢复（BackupView）

- 「导出完整备份（JSON）」：文件名 `ledger-backup-YYYYMMDD-HHmm.json`。
- 「导出表格（CSV）」：文件名 `ledger-YYYYMMDD.csv`。
- 「从备份恢复」：选择文件 → 解析并显示摘要（流水 N 条、分类 M 个、导出时间）→ 选择「合并」或「覆盖」→ 确认 → 执行。
- 说明文字：提醒将备份存到「文件 → iCloud 云盘」。

## 6. 关键算法

### 6.1 金额（`domain/money.ts`）

- 存储单位：分（整数）。
- `yuanToFen(str)`：按字符串拆分整数与小数部分计算，避免 `0.1*100` 的浮点问题。
- `formatFen(fen)`：千分位 + 两位小数。
- `fenToInput(fen)`：去掉多余的 0，如 `2050 → "20.5"`。

### 6.2 键盘输入规则

| 输入 | 规则 |
|---|---|
| 数字 | 当前数字段若为 `0` 则替换；整数部分最多 8 位 |
| `.` | 当前数字段已有小数点时忽略；段为空时补成 `0.` |
| 小数位 | 每段最多 2 位小数，超出忽略 |
| `00` | 当前段为空或已有 2 位小数时忽略 |
| `+` `-` | 表达式为空时忽略；末尾已是运算符则替换 |
| `⌫` | 删除最后一个字符 |

### 6.3 表达式求值

- 只含数字、`.`、`+`、`-`，从左到右累加，**全部转为分后用整数计算**。
- 末尾是运算符时忽略该运算符。
- 结果为负或 0 视为无效。

### 6.4 月度查询

```ts
const start = dayjs(month + '-01').startOf('month').valueOf();
const end   = dayjs(month + '-01').endOf('month').valueOf();
db.transactions.where('occurredAt').between(start, end, true, true)
  .filter(t => !t.deleted)
```

分组：按 `dayjs(occurredAt).format('YYYY-MM-DD')` 分组，组内与组间均按时间倒序。

### 6.5 备份合并

```
对备份中的每条记录 r：
  本地不存在 r.id            → 写入
  本地存在 且 r.updatedAt 更大 → 覆盖
  否则                        → 跳过
```

分类、账户等无 `updatedAt` 的表，本地不存在才写入。整个过程在一个 `db.transaction('rw', ...)` 中，任何异常回滚。

### 6.6 备份提醒

`settings.lastBackupAt` 为空且已有 ≥ 1 条流水，或距今 ≥ 14 天 → 首页显示提醒条。

## 7. 服务接口（v1.0）

```ts
// transactionService
add(input: TxInput): Promise<string>
update(id: string, input: TxInput): Promise<void>
remove(id: string): Promise<void>                // 软删除
get(id: string): Promise<Transaction | undefined>
listByMonth(month: string): Promise<Transaction[]>

// statsService（纯函数，入参为当月流水）
summarize(txs): { expense, income, balance }
byCategory(txs, type): { categoryId, amount, ratio }[]
daily(txs, month, type): number[]                 // 长度 = 当月天数

// categoryService
list(type?, includeHidden?): Promise<Category[]>
create(input) / update(id, patch) / move(id, 'up' | 'down')

// backupService
exportJson(): Promise<Blob>
exportCsv(): Promise<Blob>
parseBackup(file: File): Promise<BackupFile>      // 校验格式
importBackup(data: BackupFile, mode: 'merge' | 'overwrite'): Promise<ImportResult>
resetAll(): Promise<void>

// 文件分享
shareOrDownload(blob: Blob, filename: string): Promise<void>
```
