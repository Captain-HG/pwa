## 2. 条件模型与网址参数

```ts
type SortKey = 'time_desc' | 'time_asc' | 'amount_desc' | 'amount_asc';
type SourceKey = 'manual' | 'alipay' | 'wechat';
type RangeKey = 'month' | 'last_month' | '3m' | 'year' | 'all' | 'custom';

interface TxFilter {
  range: RangeKey;
  from?: string;          // YYYY-MM-DD，range = custom 时有效
  to?: string;
  month?: string;         // 兼容 v1.4 的 ?month=，表示某个自然月
  type?: 'expense' | 'income';
  categories: string[];   // 分类 id；一级分类包含其子分类
  minFen?: number;
  maxFen?: number;
  sources: SourceKey[];
  q: string;
  sort: SortKey;
}
```

| 参数 | 示例 | 说明 |
|---|---|---|
| `range` | `3m` | 缺省为 `month`（本月） |
| `month` | `2026-10` | 指定自然月（统计页下钻使用），优先于 `range` |
| `day` | `2026-10-27` | 兼容：等价于 `range=custom&from=to=当天` |
| `from` / `to` | `2026-09-01` | 自定义范围（含首尾两天） |
| `type` | `expense` | |
| `cats` | `exp-food,exp-traffic` | 兼容 v1.4 的单个 `category` |
| `min` / `max` | `10` / `100.5` | 单位：元 |
| `src` | `alipay,wechat` | |
| `q` | `美团` | |
| `sort` | `amount_desc` | 缺省为 `time_desc` |

`parseFilter(query, today)` 与 `toQuery(filter)` 互为逆运算，缺省值不写入网址。

## 3. 时间范围

| range | 起 | 止 |
|---|---|---|
| month | 本月 1 日 00:00 | 本月末 23:59:59.999 |
| last_month | 上月 1 日 | 上月末 |
| 3m | 两个月前的 1 日（含本月共 3 个月） | 本月末 |
| year | 今年 1 月 1 日 | 今年 12 月 31 日 |
| all | 不限 | 不限 |
| custom | from 当天 00:00（缺省不限） | to 当天 23:59:59.999（缺省不限） |

查询：有起止时间时走 `occurredAt` 索引的范围查询；`all` 时全表读取（个人数据量可接受）。

## 4. 筛选与排序（`applyFilter`）

依次：未删除 → 收支类型 → 分类（展开子分类）→ 金额（`minFen ≤ amount ≤ maxFen`）→ 来源（无 `source` 视为 manual）→ 关键词 → 排序。

- 关键词：把 `备注 / meta.counterparty / meta.goods / 分类全名` 拼接后小写，判断是否包含关键词（关键词去首尾空格、小写）。多个词用空格分隔时，**每个词都要命中**。
- 排序：时间相同时按 `createdAt` 再排；金额相同时按时间倒序。

## 5. 页面

```
‹  查询明细                         [筛选]
[🔍 搜索备注、交易对方、商品      ]
本月 ×  支出 ×  交通 ×  ¥10–100 ×   重置
排序：时间 ↓ ▾
────────────────────────────────
支出 -1,234.56   收入 +0.00   共 27 笔
（只选一个一级分类时：子分类分布）
────────────────────────────────
按时间排序 → 按天分组；按金额排序 → 平铺，每行带「10-27」日期
```

- 搜索框输入防抖 300 ms 后更新网址（`router.replace`，不产生历史记录）。
- 「筛选」打开 `FilterPanel`：编辑一份草稿，点「确定」后写入网址；「重置」清空草稿。
  - 时间：预设按钮 + 自定义时显示两个日期输入框（原生 `type=date`）。
  - 分类：按一级分类显示可多选的标签；已选的一级分类可以展开选其子分类。
  - 金额：两个数字输入框。
  - 来源：三个可多选标签。
- 排序：点击后弹出动作面板选择。
- 标题：只有「月份 + 单个分类」时显示「交通 · 2026年10月」（与 v1.4 一致），否则显示「查询明细」。

## 6. 入口

- 首页月份栏右侧增加搜索图标 → `#/list?month=<当前月份>`。
- 统计页下钻沿用 `?month=&type=&category=`，由 `parseFilter` 兼容。

## 7. 编辑交易对方 / 商品

- `TxInput` 增加 `counterparty`、`goods`：`undefined` 表示不修改，空字符串表示清除。
- `updateTx` 在事务中读取原记录，把这两个字段合并进 `meta`，其余字段（状态、单号、自动分类等）保留；`meta` 为空时删除。
- 编辑页在备注下方增加「交易对方」「商品」输入框；有值时自动展开，否则显示「＋ 交易对方 / 商品」。
- 备注是导入时自动生成的「交易对方 · 商品」（完整或截断为 50 字，可带「退款 · 」前缀）时，保存时按新值重新生成；用户自己写的备注不动。
