## 3. 在 Windows 上体验

开发完成后，可以在 Windows 上先完整体验，再决定是否部署到手机。三种方式：

### 方式 A：开发模式（改代码实时生效）

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`，按 `F12` → 点「切换设备工具栏」（`Ctrl+Shift+M`）→ 选择 iPhone 机型，即可按手机尺寸体验。

### 方式 B：生产预览（含离线能力，最接近真机）

```bash
npm run build
npm run preview
```

打开 `http://localhost:4173`。`localhost` 被浏览器视为安全来源，Service Worker 可以生效：

- 可在 Edge / Chrome 地址栏右侧点「安装应用」，在 Windows 上以独立窗口运行。
- F12 → Application → Service Workers 勾选 Offline，验证离线可用。

### 方式 C：手机局域网预览（只看界面）

```bash
npm run dev -- --host
```

iPhone 与电脑连同一 Wi‑Fi，Safari 访问终端里打印的 `http://192.168.x.x:5173`。
注意：非 HTTPS，无离线能力；且这里记的数据与将来正式安装的 PWA 不互通，仅用于看效果。

> Windows 浏览器里的数据存在该浏览器的 IndexedDB 中，与手机不互通。如需带过去，可用「导出 JSON → 手机上导入」。

## 4. 部署到 iPhone（体验满意后）

见 [部署说明.md](部署说明.md)：`npm run cf:login` → `npm run cf:create` → `npm run deploy`，然后在 iPhone Safari 打开正式地址并添加到主屏幕。

| A08 | 退出登录 | 本机数据被清除，回到登录页；重新登录后数据从云端恢复 |
| A09 | 跨站 POST（Origin 不同） | 403 |

### 6.2 同步

## 10. 验收用例

| 编号 | 用例 | 预期 |
|---|---|---|
| I01 | 导入支付宝账单 | 正确识别为支付宝，条数、总金额与账单一致（扣除跳过的记录） |
| I02 | 导入微信账单 | 正确识别为微信，同上 |

| I06d | 手动记过的一笔（金额相同、时间相差 30 分钟内） | 标为疑似重复，默认不导入，可勾选导入 |
| I07 | 金额带千分位、「¥」前缀 | 金额按分精确，无浮点误差 |
| I08 | 在预览中把某交易对方改为「购物」 | 本次全部生效；下次导入自动命中；另一台设备同步后也生效 |
| I09 | 无关文件、缺少必需列的文件 | 提示无法识别 / 缺少某列，不写入任何数据 |
| I10 | 导入后在另一台设备上 | 同步后可见；再导一次同一文件不重复 |
| I11 | 没有 `bill.import` 权限的用户 | 看不到入口；直接访问 `#/import` 被拦回；推送 rules 返回 403 |
| I12 | 删除某条导入记录后重新导入 | 默认不恢复；勾选「之前删除过的记录」后恢复，并同步到其他设备 |
